**Quetza** — модульный фреймворк на TypeScript для Discord-ботов. Он позволяет собирать приложения из самодостаточных независимых модулей.

Архитектура Quetza переносит разработку новой функциональности из модификации ядра в добавление отдельных модулей.

## Основные возможности

- **Обнаружение модулей по соглашениям:** создайте папку, и Quetza автоматически загрузит её как модуль.
- **Изоляция контроллеров:** управление состоянием происходит на уровне сервера (guild), что исключает утечки данных между серверами.
- **Декларативные команды:** определение слэш-команд Discord через типизированный интерфейс.
- **Реактивные события:** подписка на любые события Discord.js внутри модулей.

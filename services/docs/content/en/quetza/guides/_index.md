**Quetza** guides provide step-by-step instructions for common tasks and workflows. These documents focus on practical application of the framework's concepts.

## Core Workflows

The development and operation of Quetza bots revolve around three primary workflows:

1.  **Module Development:** Creating new features by adding self-contained modules.
2.  **Deployment & Operations:** Running the bot in various environments (Docker, Source).
3.  **Lifecycle Management:** Maintaining modules from creation to deprecation.
